## BUG 清单（本轮）

### 真实 BUG（已修）

| ID | 级别 | 模块 | 根因 | 修复 |
|----|------|------|------|------|
| **E2E-1** | P0 🔴 | `e2e/helpers.ts:10-11` | `BFF_BASE` 默认 `127.0.0.1:3000`（应为 3100）；`BACKEND_BASE` 默认 `8081`（应为 8080）；env 名 `LUBAN_BFF_BASE`/`LUBAN_BACKEND_BASE` 与 ai/leads.spec 的 `LUBAN_E2E_BFF_URL` 不一致 | 统一为实际端口 + env 名对齐 `LUBAN_E2E_BFF_URL`/`LUBAN_E2E_BACKEND_URL` |
| **E2E-2** | P1 🟡 | `e2e/ai.spec.ts:103` | AI 服务 URL 用 `BFF_URL.replace(':3100', ':8000')` 字符串替换推断——脆弱，且 BFF 与 AI 服务解耦原则相悖 | 改为独立 env `LUBAN_E2E_AI_URL ?? http://127.0.0.1:8000` |
| **E2E-3** | P1 🟡 | `e2e/helpers.ts:24` | 凭据硬编码 `admin/admin123`，与 `auth.setup.ts` 用 env 不一致 | 改读 `LUBAN_E2E_ACCOUNT/PASSWORD` env，未配置时 fallback `admin/admin123`（本地零配置）|
| **E2E-4** | P1 🟡 | `e2e/designer-node-ops.spec.ts:65` N1 | spec 直接 `cloneBtn.click()`，但 OutlineTree 的 actions 按钮 CSS 默认 `display:none`，仅 `.lb-outline-node__row:hover` 才显示 → 60s 元素不可见超时 | 先 `firstRow.hover()` 触发显示，再 `await expect(cloneBtn).toBeVisible()` 后 click（模拟真实用户行为）|

### 重复定义消除（DRY）

- `e2e/leads.spec.ts:27` 内联 `process.env.LUBAN_E2E_BFF_URL ?? '...'` → 复用 `helpers.ts` 的 `BFF_BASE`
- `e2e/ai.spec.ts:18` 内联同上 → 复用 `BFF_BASE`
